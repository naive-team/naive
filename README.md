# NAIVE - Source Code
## Games On Web 2026, AI Edition

This project is a 3D puzzle game developed with Babylon.js and Typescript for the French "Games on Web" contest.

_This game was made by humans, for humans._

##  How to run

```
npm install
npm run dev
```

## Controls
- **WASD**:  Move
- **Mouse**: Camera
- **Space**: Catch
- **F**: Interact
- **Click**: Interact (in dialogs)
